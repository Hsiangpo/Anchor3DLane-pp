### 2026-05-10：projection-aware local lane-strip sampling

- 时间节点：2026-05-10 13:24 完成 OpenLane validation 评估。
- 核心创新点：原始 Anchor3DLane++ 在每个 3D anchor 投影点上只采样一个图像特征点，远处车道线较细且投影误差会导致特征采样偏离车道证据。本实验在投影点横向采样 `[-1, 0, 1]` 三个局部 offset，并用可学习 softmax 权重聚合，让模型在不改变 matcher、loss 和后处理阈值的前提下获得轻量的局部几何容错。
- 代码改动：
  - `mmseg/models/lane_detector/anchor_3dlane_pp.py` 增加可选 `strip_sample`、`strip_offsets`、`strip_center_bias`、`strip_apply`，默认关闭，baseline 配置行为不变。
  - `configs_v2/openlane/experiments/anchor3dlane++_r50x2_strip_sample.py` 开启 `strip_sample=True`，设置 `strip_apply='final'`，仅作用于最后 refinement 输出。
  - 训练使用 2-GPU DDP，`samples_per_gpu=3`，从官方 checkpoint 初始化，显存约 27.4GB/卡。
- 训练与评估：
  - 训练日志：`logs/train_strip_sample_20260510_121835.log`。
  - 评估日志：`logs/eval_strip_sample_20260510_131335.log`。
  - checkpoint：`output/openlane/experiments/strip_sample_r50x2/iter_10000.pth`。
  - 结果文件：`output/openlane/experiments/strip_sample_r50x2_eval/evaluation_result.json`。
- 消融结果：
  - Baseline：F1 62.404481，recall 61.326885，precision 63.520625，category accuracy 93.378974。
  - `strip_sample final-only`：F1 62.521121，recall 60.981647，precision 64.140336，category accuracy 93.446812。
  - F1 提升：`+0.116639` 分。
- 结论：该局部 strip 采样主要提升 precision 和类别准确率，recall 小幅下降，但总体 F1 高于当前稳定 baseline。该方向值得作为新的稳定版本保留，并在后续围绕“投影不确定性建模 + 证据聚合”继续做更强的结构设计。

### 2026-05-10：V-DCC / visibility-weighted differential curve consistency

- 时间节点：2026-05-10 22:28 完成 OpenLane validation 评估。
- 核心创新点：在稳定 `strip_sample` 的局部图像证据增强基础上，增加 final-only 的可见性加权 3D 曲线微分一致性监督。具体做法是对 GT 可见点上的预测 `x` 曲线计算一阶斜率和二阶曲率，并与 GT 曲线微分量做 SmoothL1 约束；`y` 方向使用真实 anchor y-step 间距归一化，因此监督的是 3D 几何形态变化，而不是逐点坐标的重复惩罚。该方法不新增模型参数、不改 matcher、不改后处理阈值、不改 visibility loss，降低了破坏现有 precision 的风险。
- 代码改动：
  - `mmseg/models/losses/lane_loss_v2.py` 增加可选 `curve_geom_losses` 分支，以及 `curve_geom_axes`、`curve_slope_weight`、`curve_curv_weight` 参数。
  - 新增 `axis_curve_geom_loss()` 和 `curve_geom_loss()`，仅在相邻 GT 点都可见时计算 slope loss，仅在连续三点可见时计算 curvature loss，并用 `anchor_y_steps_tensor` 做真实 y-step 归一化。
  - `configs_v2/openlane/experiments/anchor3dlane++_r50x2_vdcc.py` 从 `strip_sample_r50x2/iter_10000.pth` 加载，设置 `samples_per_gpu=3`、`lr=1e-5`、`max_iters=10000`，只在最后 feature level 的最后 refinement 上启用 `curve_geom_losses=0.05`。

- 消融结果：
  - 官方 checkpoint baseline：F1 62.404481，recall 61.326885，precision 63.520625，category accuracy 93.378974。
  - `strip_sample final-only`：F1 62.521121，recall 60.981647，precision 64.140336，category accuracy 93.446812。

### 2026-05-12：EAC-DR / evaluator-acceptance calibrated duplicate reranker

### 2026-05-12：FRT-EAT / Frenet Road-Ribbon Topology with Evaluator-Aware Training

- 时间节点：2026-05-12 06:06 完成 OpenLane validation 评估。
- 核心创新点：在 EAC-DR 的 evaluator-aware 校准框架上，引入 GT lane-local road ribbon 拓扑约束。传统 evaluator 只看逐点 3D 距离、cover 和 purity，可能把局部串入邻车道 ribbon 的候选也当成可接受正样本；FRT-EAT 用同一 y-step 上相邻 GT lane 的横向间距估计局部 ribbon width，只在存在可见邻车道时判定拓扑违规。违规的 evaluator-positive proposal 不转成 hard negative，而是从正样本中 ignore，并在 duplicate ranking cost 中加入小权重 ribbon violation，避免 PC-Aug 式 recall 崩塌。
- 代码改动：
  - `mmseg/models/losses/lane_loss_v2.py` 增加可选 `frt_enable`、`frt_min_width`、`frt_default_width`、`frt_max_width`、`frt_slack`、`frt_dirty_thresh`、`frt_rank_weight`。
  - 新增 `build_ribbon_widths()` 和 `ribbon_pair_violation()`，只在目标 lane 的该 y-step 存在可见邻车道时启用 ribbon 惩罚，单车道和缺邻车道 y-step 不误罚。
  - `acceptance_labels()` 在 `frt_enable=True` 时把 dirty evaluator-positive proposal 置为 ignored，并把 duplicate ranking 的几何 cost 改为 `hit_cost + frt_rank_weight * ribbon_violation`。
  - `configs_v2/openlane/experiments/anchor3dlane++_r50x2_frt_eat.py` 从 `eac_dr_r50x2/iter_10000.pth` 加载，保持 `freeze_base=True`，只训练 `accept_calib_head.*`，`samples_per_gpu=3`，`lr=5e-5`，`max_iters=8000`。
- 训练前验证：
  - 本地与远端 `py_compile`、`git diff --check` 通过。
  - 远端 config/model/checkpoint load 通过；只存在 `accept_calib_head.*` 六个可训练参数。
  - 合成 sanity 通过：exact-GT proposal 被接受；串入邻车道的 evaluator-positive proposal 被 ignore；单车道场景不触发 FRT dirty。
  - Code Review 子代理结论 PASS，无 blocking OOM、DDP、张量维度、checkpoint-load、梯度爆炸或失败路线重复问题。
  - 1-iter 和 20-iter 双卡 DDP smoke 通过，显存约 `18974MB`，`batch_frt_dirty` 有正常非零信号，无 OOM/NaN/Traceback/Killed/DDP hard error。
- 训练与评估：
  - 训练日志：`logs/train_frt_eat_20260512_053600.log`。
  - 评估日志：`logs/eval_frt_eat_20260512_055533.log`。
  - checkpoint：`output/openlane/experiments/frt_eat_r50x2/iter_8000.pth`。
  - 结果文件：`output/openlane/experiments/frt_eat_r50x2_eval/evaluation_result.json`。
- 消融结果：
  - 官方 checkpoint baseline：F1 62.404481，recall 61.326885，precision 63.520625，category accuracy 93.378974。
  - `strip_sample + V-DCC + EAC-DR`：F1 62.549877，recall 61.625759，precision 63.502132，category accuracy 93.595711。
  - `strip_sample + V-DCC + EAC-DR + FRT-EAT`：F1 62.554667，recall 61.647158，precision 63.489294，category accuracy 93.586380。

- 结论：FRT-EAT 是一个极小幅但真实的 recall-oriented 增益，说明 evaluator-aware 校准里加入局部 lane-ribbon 拓扑过滤能补回少量真阳性，同时没有像 PC-Aug 那样造成 recall 崩塌。该方向仍不足以解决 65 分目标，后续必须继续寻找更强的结构性创新；不要把 FRT 参数微调当作主线，只能作为当前稳定校准头的一部分保留。

### 2026-05-12：LPF-T / Lane-Point Field Transformer

- 时间节点：2026-05-12 09:03 完成 OpenLane validation 评估。
- 核心创新点：在 `strip_sample + V-DCC + EAC-DR + FRT-EAT` 的稳定分支上，把 final-stage 的 anchor point 特征从直接 flatten 成 lane token，改为先经过一个轻量 lane-point field transformer。该模块在 `[B, C, N=30, L=20]` 特征上分别做纵向 attention（同一车道的 20 个 y-step）和横向 attention（同一 y-step 的 30 个候选槽位），再用零初始化输出投影和 sigmoid 门控回灌。它不改候选数、matcher、NMS、阈值和后处理，只增强最终分类/回归前的结构化 lane-point 表达。

### 2026-05-12：LOF-OC / Lane Ownership Field with Ownership Contrast

- 时间节点：2026-05-12 11:39 完成 OpenLane validation 评估。
- 核心创新点：在 `strip_sample + V-DCC + EAC-DR + FRT-EAT + LPF-T` 的稳定分支上，引入 final-only 的 Lane Ownership Field。该模块不增加候选数、不改 matcher/NMS/阈值，而是在最终 `[B, C=128, N=30, L=20]` lane-point token 上建立 30 个候选槽位之间的 ownership relation，并用 evaluator-clean、FRT-clean、unique-owner 规则生成 ownership 监督。训练时对同一 GT lane 的 clean owner proposal 做 contrastive relation 约束，同时用 lane-level MIL 让多个 clean owner 支持同一车道分类，并把 owner-clean 候选从背景负样本池移除，避免 clean duplicate 被背景分类 loss 压低。

- 结论：LOF-OC 成功补回 LPF-T 牺牲的一部分 recall，并把当前稳定成绩推到 62.574061。该增益仍然很小，说明 ownership/MIL 可以缓解背景负样本压制 clean duplicate 的问题，但还没有解决 65 分目标需要的大幅候选覆盖和远处弱证据问题。后续优先考虑更强的密集图像证据监督或 coverage-constrained score adapter，而不是只继续调 ownership loss 权重。
