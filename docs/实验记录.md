## 成功实验

### 2026-05-10：projection-aware local lane-strip sampling

- 时间节点：2026-05-10 13:24 完成 OpenLane validation 评估。
- 核心创新点：原始 Anchor3DLane++ 在每个 3D anchor 投影点上只采样一个图像特征点，远处车道线较细且投影误差会导致特征采样偏离车道证据。本实验在投影点横向采样 `[-1, 0, 1]` 三个局部 offset，并用可学习 softmax 权重聚合，让模型在不改变 matcher、loss 和后处理阈值的前提下获得轻量的局部几何容错。
- 代码改动：
  - `mmseg/models/lane_detector/anchor_3dlane_pp.py` 增加可选 `strip_sample`、`strip_offsets`、`strip_center_bias`、`strip_apply`，默认关闭，baseline 配置行为不变。
  - `configs_v2/openlane/experiments/anchor3dlane++_r50x2_strip_sample.py` 开启 `strip_sample=True`，设置 `strip_apply='final'`，仅作用于最后 refinement 输出。
  - 训练使用 2-GPU DDP，`samples_per_gpu=3`，从官方 checkpoint 初始化，显存约 27.4GB/卡。
- 训练与评估：
  - 训练日志：`logs/train_strip_sample_20260510_121835.log`。
  - 评估日志：`logs/eval_strip_sample_20260510_131335.log`。
  - checkpoint：`output/openlane/experiments/strip_sample_r50x2/iter_10000.pth`。
  - 结果文件：`output/openlane/experiments/strip_sample_r50x2_eval/evaluation_result.json`。
- 消融结果：
  - Baseline：F1 62.404481，recall 61.326885，precision 63.520625，category accuracy 93.378974。
  - `strip_sample final-only`：F1 62.521121，recall 60.981647，precision 64.140336，category accuracy 93.446812。
  - F1 提升：`+0.116639` 分。
- 结论：该局部 strip 采样主要提升 precision 和类别准确率，recall 小幅下降，但总体 F1 高于当前稳定 baseline。该方向值得作为新的稳定版本保留，并在后续围绕“投影不确定性建模 + 证据聚合”继续做更强的结构设计。
